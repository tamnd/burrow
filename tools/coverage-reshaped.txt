# Signatures that are not the shape tools/burrow-coverage expects, on purpose,
# one per line, as
#
#     package: declaration: reason
#
# The declaration is spelled the way tools/burrow-coverage -v prints it. The
# reason says why the C signature departs from the rules, and the header it
# points at argues it in full. A line here is a promise that the difference is
# a design decision rather than a slip, so it gets the same review as a waiver.

# include/burrow/context.h: Go returns only the stop function and leaves the
# registration to the collector. Here the registration is the Context that comes
# back, because that is what context_release frees, and stop is an out parameter.
context: func AfterFunc: the registration is returned so it can be freed, stop comes back through a pointer

# include/burrow/context.h: burrow does not have the calendar half of time yet,
# so a deadline is a reading of the monotonic clock in nanoseconds. Both take a
# Time once it exists.
context: func WithDeadline: the deadline is monotonic nanoseconds until time.Time is ported
context: func WithDeadlineCause: the deadline is monotonic nanoseconds until time.Time is ported

# include/burrow/error.h: errors_as returns the typed pointer, or NULL, which is
# the shape Go added AsType to get, and takes the target as a type descriptor
# because C has no pointer to an interface type to pass instead.
errors: func As: returns the matched error's pointer, NULL for no match, and takes a type descriptor

# include/burrow/sync.h, sync.Map: keys and values go in and come out by
# pointer, because the map learns their types at run time, and every call that
# can allocate returns whether it could, with Go's own result moved to an out
# parameter.
sync: method (*Map) Load: keys and values by pointer, the found flag is the result
sync: method (*Map) Store: keys and values by pointer, returns false if it could not allocate
sync: method (*Map) Swap: keys and values by pointer, returns false if it could not allocate
sync: method (*Map) LoadOrStore: keys and values by pointer, returns false if it could not allocate
sync: method (*Map) LoadAndDelete: keys and values by pointer, the found flag is the result
sync: method (*Map) Delete: keys by pointer
sync: method (*Map) CompareAndSwap: keys and values by pointer, returns false if it could not allocate and the swap comes back through a pointer
sync: method (*Map) CompareAndDelete: keys and values by pointer
sync: method (*Map) Range: the callback is a function pointer with a context argument, and gets the key and value by pointer

# include/burrow/strconv.h: the Error method of a NumError built by hand has to
# put its message somewhere, so it takes the allocator Go's string result would
# have come from. An error from a Parse function already carries its text, and
# error_text reads it without one.
strconv: method (*NumError) Error: takes the allocator the message is built in

# include/burrow/encoding/base64.h: an Encoding holds no pointers, so the calls
# that make one return it by value and the caller keeps it wherever it likes.
# A pointer would need an allocator and a free for a few hundred bytes.
encoding/base64: func NewEncoding: returns the Encoding by value
encoding/base64: method (Encoding) WithPadding: returns the Encoding by value
encoding/base64: method (Encoding) Strict: returns the Encoding by value

# include/burrow/encoding/base32.h: the same as base64, an Encoding is a plain
# value.
encoding/base32: func NewEncoding: returns the Encoding by value
encoding/base32: method (Encoding) WithPadding: returns the Encoding by value

# include/burrow/io.h: the small wrappers Go returns as an interface or a
# pointer to a fresh value come back as the struct itself, so they can live on
# the stack with nothing to free. The _as_ functions make the interface from
# its address.
io: func LimitReader: returns the IoLimitedReader value, io_limited_reader_as_io_reader makes the Reader
io: func TeeReader: returns the IoTeeReader value, io_tee_reader_as_io_reader makes the Reader
io: func NopCloser: returns the IoNopCloser value, io_nop_closer_as_io_read_closer makes the ReadCloser
io: func NewSectionReader: returns the IoSectionReader value rather than a pointer to a new one
io: func NewOffsetWriter: returns the IoOffsetWriter value rather than a pointer to a new one

# include/burrow/io.h: these have to allocate, so they take an allocator, and a
# variadic list in C is a pointer and a count.
io: func MultiReader: takes an allocator and the readers as a pointer and a count
io: func MultiWriter: takes an allocator and the writers as a pointer and a count
io: func Pipe: takes an allocator and returns both ends through out parameters

# include/burrow/bufio.h: a ReadWriter is two pointers and nothing to
# allocate, so it comes back by value.
bufio: func NewReadWriter: returns the struct by value, since it holds only the two pointers

# include/burrow/encoding/csv.h: the Error method of a ParseError built by hand
# has to put its message somewhere, so it takes the allocator, as NumError's
# does. An error from the reader already carries its text.
encoding/csv: method (*ParseError) Error: takes the allocator the message is built in
